# 銷售 AI 教練

公勝保經高雄業務中心的銷售情境教練。輸入個案後，可取得分析與話術建議，並與 AI 客戶角色扮演，結束時取得講評。

## 四個模組

| 模組 | 範圍 |
| --- | --- |
| 主顧開拓 與 電話約訪 | S1–S2 名單、定聯與約訪 |
| 需求分析・找痛點 | S3–S4 初步面談、發掘與深化需求 |
| 說明建議書 | S5 建議書呈現、年期與額度 |
| 成交與轉介 | S6 反對問題、成交與轉介 |

每個模組的教練規則、方法論與範例個案位於 `content/modules/<模組 ID>/`。模組登錄在 `lib/modules.ts`。

## 使用流程

1. 選擇模組，輸入客戶背景、進度、關鍵句與練習目標，或載入範例，再點選「開始個案分析」。
2. 依教練建議追問；需要練習時點選「開始角色扮演」。
3. 點選「結束對練並取得講評」以取得回饋。

輸入框支援多行。按 Enter 換行，按 ⌘/Ctrl + Enter 送出。教練回覆可複製；失敗時可重試。

## 資料處理與法遵

個案內容會即時送至第三方 AI 服務 Anthropic 進行分析，本軟體本身不設資料庫、不登入、也不留存任何對話紀錄——瀏覽器重新整理後，畫面中的對話就會消失。請勿將 AI 建議視為公司核准話術、商品建議或法遵審核結果。

正式開放團隊使用前，應完成權限與費用控管。

## 本機執行

```bash
npm ci
cp .env.example .env.local
npm run dev
```

在 `.env.local` 設定 `ANTHROPIC_API_KEY`，然後開啟 http://localhost:3000。可用 `ANTHROPIC_MODEL` 指定模型。執行 `npm run lint` 做 TypeScript 靜態檢查，執行 `npm run build` 確認建置。

## 部署

可將 GitHub repo 連接 Vercel，並在部署環境設定 `ANTHROPIC_API_KEY`。不要把 API 金鑰提交到 Git。

## 對話上限與範例載入

一般追問會預留最後講評的容量；接近上限時，請點選「取得總結並結束本次對話」，複製講評後再開啟新個案。系統不會刪減既有對話或用摘要取代原始內容。過長的待送訊息會留在輸入框，可縮短後再送出。請求失敗時，重試會沿用原本的模式與結束動作。

範例載入途中，切換模組、修改個案文字或開始分析都會取消舊的載入；舊結果與舊錯誤不會覆蓋目前畫面。

## 回歸測試

```bash
npm test
npm run lint
npm run build
```

元件測試模擬 AI 回覆，不需要 API 金鑰，也不會呼叫第三方 AI；涵蓋訊息數與長度預算、最後講評與重試，以及範例載入競態。
