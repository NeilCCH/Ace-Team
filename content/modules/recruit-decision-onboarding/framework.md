# 增員 R5-R6 框架卡

## 一、R5 心法：希望

不論準增之前的問題是什麼，到了 R5 這個階段，都應該讓準增覺得「來這個
行業是充滿希望的」。

## 二、R5 技法：380 話術（完整逐字稿）

380 話術是壽險業「收入累積、越做越穩」優勢的完整呈現，暖身很重要，
不能一上來就講制度。

### 暖身句
```
「OO，我現在可能要花 5 分鐘時間跟你談談我們的業務制度，坦白說我非常
不喜歡談業務制度，因為業務制度講了很現實，坦白說吸引一個人不該只有
收入，可能是成長、可能是晉升、可能是不一樣的領域、可能是關懷，可是
每一個人來工作，收入是一個最基本的東西對嗎？所以我還是有必要告訴你，
你要怎麼做、朝哪個方向走才可以獲得最大利益，所以等一下你花 5 分鐘，
只要 5 分鐘就好，可以嗎？」
```

### 第一段：逐年累積
```
「OO，如果從現在開始我們認真跑客戶，每週拜訪 5 個客戶，5 個客戶中，
我們只要成交一件年繳 24000 的醫療險，一個月繳 2000 的保單，這樣也不
是太難對嗎？如果每個禮拜都這樣做，一年有 52 週，每週成交一件，你知道
第一年年薪是多少嗎？38 萬。重點不在第一年，而是第二年你做一樣的事，
年薪是 54.2 萬；第三年你做一樣的事，年薪是 67.5 萬，連續做 10 年，第
10 年你的薪水是 149 萬，你覺得好嗎？你有沒有發現，做一樣的事情，我們
收入卻越來越高？這就是保險業很特別的優勢：累積！我們做的每一塊錢
業績都會被累積下來，讓我們的收入越來越高、越來越穩定，這樣你覺得好
嗎？」
```

### 第二段：不跑 case 也有收入
```
「OO，如果我告訴你，從第 11 年開始，你一件 case 都不做，但年收入還是
穩穩站上 100 萬，你覺得好嗎？不用懷疑，這就是保險業累積的力量。客戶
只要有續繳保費，我們就能持續領續期獎金，所以我們一定要把客戶服務好
對嗎？就實務來說，我們不會什麼都不做，但你所做的所有業績、所有獎勵，
都會從這 100 萬往上堆疊，讓你的收入更高，你覺得好嗎？」
```

### 第三段：二十年總累積
```
「OO，一年做 38 萬業績，我們穩定做 10 年，10 年幫公司創造 380 萬業績，
20 年後你知道總共可以領到多少獎金收入嗎？猜猜看！如果我告訴你，可以
領到 2062 萬，你覺得好嗎？你看喔，做 380 萬的業績，但卻可以領到 2062
萬，你會不會覺得很誇張？」
```

### 收尾（最重要）：從利益轉回願景
```
「OO，我不是要跟你說保險業可以賺很多錢，如果不努力跑客戶，一毛錢都
賺不到不是嗎？我只是想說，一個在保險業願意努力的人，他所做的一切都
會被累積，只要做好自己的工作、服務好客戶，這 100 萬是會不離不棄的
100 萬，小孩不一定會照顧我們，但這 100 萬會，你覺得好嗎？」
```

**★最後收尾最重要，說的內容要自己內心先認同**：制度說得太利益，吸引
不到真正有願景的準增——**能驅使人的是願景，不是利益（增員是理念
共享）**。所以最前面需要暖身，結尾時的共鳴與感動要多加自己的元素，
強調「為自己打拼的一切都是值得的」。

### 380 話術的使用時機
建議對象：A 級客戶、臨門一腳、行業比較。**如果沒做好，可能會讓準增
覺得**：你很直銷、賣保險賺我很多錢、很市儈——所以務必先暖身、確認
對方已經準備好聽制度，才進入 380 話術。

## 二之一、20 分鐘 OPP：涵蓋面更廣的制度說明完整流程

除了 380 話術（聚焦在「收入累積」），公司還有一套更完整的「20 分鐘
OPP」五大綱要，涵蓋表誠意、談制度、怎麼做、談資源、誠信大五個部分，
比 380 話術多了「公司資源」與「公司穩定度／誠信」兩塊論述，適合對
公司整體還半信半疑、而不只是在意收入曲線的準增。這套流程結構嚴謹、
前後呼應，建議業務員熟記整體脈絡（跟 380 話術一樣），但**具體數字會
隨年度調整，使用前務必跟主管核對當年度最新資料，不要套用舊數字**。

### 五大綱要
1. **表誠意**：開場先降低對方戒心——「如果沒有辦法符合你最大利益，
   你不用做任何的考慮，我們談話一定會以你最大利益為前提，如果做不到
   這件事情我們隨時終止談話好嗎？」先把「我不是要硬推銷」講清楚，再
   進入正題。
2. **談制度**：用「韓都衣舍海星模式」故事起頭（員工只對遊戲規則負責，
   不用刻意討好管理者，工作效率就會大大提升）帶出保經的分潤邏輯——
   業務員領大部分、公司留小部分（相對保險公司業務體系、傳統行業的
   分潤比例低很多），解釋「這份差距本來就是業務員該領的」。接著用
   具體年期（例如 2 年期／6 年期／20 年期）保單案例，對比「保經事業部
   範例」與「一般保險公司業務經理範例」的實際 FYC／FYA 數字，讓對方
   自己算出差距有多大（常見落差是 2–3 倍）。比較時態度上要先認同對方
   可能的疑慮，不是爭論對錯：「我寫的對不對你可以自己查」。
3. **怎麼做**：說明完整的獎勵結構，讓準增知道「做到什麼程度，可以領到
   什麼」：
   - **五大佣酬**：首年佣金、續佣、年終獎金、服務津貼、繼續率獎金
   - **現金加碼**：學習金幣（年度達一定 FYA 門檻可再領一筆補助課程
     費用）、購物金、開門紅、不定期加碼
   - **旅遊競賽**：國內／海外旅遊資格，用 FYA 計算
   - **專屬財補**：針對事業部以上高階主管的額外獎金
4. **談資源**：公司在制度之外投入的資源——學習地圖（多條學習地圖、
   多系列實戰課程）、學習金幣、頂尖業務的交流社群（MDRT／IDA 以上
   才能申請）、高端客群經營工具（例如高爾夫球隊）、數位平台、年度
   表揚大會、海外旅遊、賽中賽。核心訊息：「保經只給高佣金、沒有教育
   訓練」這句話不適用於這家公司。
5. **誠信大**：收尾用公司的規模與穩定度建立信任——市占率數據（經代
   業成長率是整體經代業好幾倍）、財務表現（連續多年保經業財務績效
   數一數二）、具體的誠信故事（例如某次重大天災後，公司持續依約撥付
   同仁獎金、協助同仁度過難關），最後強調三大傳承優勢：**離職可續領、
   身故可繼受、生前可傳承**。

### 使用建議
- 跟 380 話術一樣，收尾不要只停在數字——制度講得太利益，會讓準增
  覺得「很市儈」。
- 這套流程比較長（完整跑完建議抓 20 分鐘），適合已經進入 R5、對公司
  整體還有疑慮但值得花時間深談的對象；如果準增已經很篤定、只差臨門
  一腳，380 話術的精簡版可能更合適。
- **教練提醒**：具體的分潤比例、獎勵金額、資格門檻屬於公司內部時效性
  資料，示範時可以引用架構與邏輯，但務必提醒業務員向主管確認當年度
  最新數字，不要憑舊教材裡的數字去跟準增承諾。

## 三、同業增員：展現高度、切主戰場

同業增員的順序是先做 R4、R5，最後才做 R3。同業已經懂保險，所以 R4-R5
階段的重點是**展現高度**（不是被動比制度、比佣金）與**切中對方的主戰場**
（找到對方真正在意的那個點：直轄精神沒有門檻、事業部利益永續發展、
傳承世襲、15% 服務津貼、繼續率獎金、組織複利）。

### 案例參考
- **34 歲女性，證券主管，104 call 來的**：已經面談六家保險公司，氣勢
  很強、只想比制度。這種對象適合展現高度（教育訓練投入、組織複利），
  而不是陷入純粹的制度數字比較。
- **35 歲女性，富邦前同事**：交情不錯，但對原單位仍有向心力、沒有明顯
  推力。這種對象適合先維持關係、不強求，等待對方自己出現推力的時機。

### 傳承篇（針對資深、高資產同業或候選人的補強話術）
掌握主控權對抗特留分、一筆立即的現金預留稅源、3330（善用國家賦予每個
國民應有的合法權利）、分期給付保險金——這些是商品／制度面向的補強
素材，用來加深對方對公司專業度的信任，實際使用時仍要先確認這是不是
對方的主戰場。

## 四、R6 心法：設定目標，取得工作承諾書

先了解新人的收支狀況、工作動機等相關背景，在輔導時間與新人達成共識
後，再與新人一同討論工作說明承諾書，並一起設定活動量目標，達成收入
目標。**順序很重要**：先了解背景與動機、達成共識，才進入白紙黑字的
承諾書與目標設定，不要一開始就丟一份表格要新人簽名。

## 五、R6 技法：時程推進（完整報聘流程）

```
1. 考照
   報名時間 → 考試時間 → 模考時間 → 成績出來

2. 報聘到登錄
   確認報名＋面談時間
   準備文件：報聘書、自然人憑證、身分證副本、畢業證書

3. 登錄後
   拿到密碼函，完成帳號密碼變更
   完成業訓 e 學堂課程

4. 考外幣或投商證照
   考外幣須先上過外幣課程
   考投商須於報名前 10 天完成年金測驗
```

**教練診斷邏輯**：檢查主管有沒有主動跟催每一步的時程（報名／考試／
模考／文件），而不是把整個流程丟給新人自己摸索——新人在這個階段最
容易因為流程繁瑣而卻步，主管的主動跟催是報聘能不能順利完成的關鍵。

## 六、教練回饋輸出格式（建議）

1. **現況釐清**：目前走到 R5 或 R6 的哪個環節、是白紙還是同業增員
2. **目標對照**：R5 該做到的事（希望、380 話術完整鋪陳、收尾轉回願景）
   或 R6（了解動機共識、完整跑完報聘流程）
3. **落差診斷**：暖身夠不夠、380 話術講完整了嗎、收尾有沒有轉回願景、
   同業增員有沒有找對主戰場、報聘流程有沒有跟催到位
4. **行動建議**：具體的暖身句、380 話術段落、主戰場話術，或報聘時程
   跟催提醒
5. **檢核演練**：邀請主管角色扮演練習這場關鍵面談
