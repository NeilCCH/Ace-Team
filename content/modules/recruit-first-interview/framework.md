# 增員 R3 框架卡

## 一、R3 心法：一次面談是為了判斷推力，不是為了增員對方

```
同理心 → 讚美 → 找出推力 → 確認推力 → 差異化
```

- **同理心**：有沒有將心比心，站在對方的立場，思考他所有的面向（包含
  工作和生活，因為工作也僅是生活的一部分）？若能融入對方的情緒，往往
  比講完整套話術流程更重要。
- **讚美**：多讚美準增，正向肯定。人與人之間不是話術講得好就好，也不要
  為了講而講——我們要先降低對方防備心、建立信任感。
- **差異化＝反其道而行，弱化自己**：講出超出對方預期的話，才會讓對方
  更認真思考。範例：如果一個準增同時面對兩位業務員增員，一位一直說
  保險業多好、我的單位多棒，另一位卻說「保險不好做喔！如果不認真做不
  會成功喔！」——後者反而因為說法客觀誠實，更容易讓準增接受。

## 二、推力的主觀與客觀

| 類型 | 說明 | 常見項目 |
|---|---|---|
| 客觀推力 | 不偏頗、公正，科學方法可衡量，不受意識影響而獨立存在 | 薪水、工時長、加薪幅度低、升遷困難、工作分配不公 |
| 主觀推力 | 帶有自己的看法，受個人情緒與喜好影響，結果因人而異 | 同事相處問題、老闆有問題、環境不好、距離遠、學習受限制 |

**情緒會讓推力從客觀變主觀**：在跟準增對談時，當他談論工作很有情緒，
即使推力原本是客觀因素，也會變成主觀因素。多數人真正讓人迫不及待離職
的原因，往往是主觀因素（例如跟主管處不來），而不是薪水這類客觀因素。

R1→R2→R3 屬於感性階段（主觀 > 客觀），R4 是感性理性的交界，R4→R5→R6
屬於理性階段（客觀 > 主觀）。

## 三、聊天三技巧：跟追、第三人、個人觀察（附完整對話示範）

跟需求分析模組共用同一套聊天技巧：**跟追**（順著對方的話往下問）、
**第三人**（「你同事是不是也有一樣的問題？」降低戒心）、**個人觀察**
（把觀察到的細節說出來，讓對方感覺被關注），並隨時搭配同理心。

**完整示範對話**：
```
業務：寶寶，最近工作好嗎？
對方：還好啊！就是有一點累。
業務：累！是哪方面累啊？（跟追）
對方：就上班啊，主管交辦的事又多又急，讓我有點力不從心。
業務：我可以體會你的難處。（同理心）那你同部門的同事也有一樣的問題
      嗎？一樣一直被交辦事情？（第三人）
對方：大家感覺都很忙，但是我覺得自己被交辦特別多任務，常常要開會、
      要報告進度，我都被追得喘不過氣來了。
業務：哇！這樣真的很麻煩。（同理心）難怪你回 LINE 的速度及口氣跟平常
      不太一樣。（個人觀察）
對方：喔！怎麼說？
業務：你以前回 LINE 很快，而且口氣很輕鬆，但最近回的速度變慢了，內容
      上也顯得些許的不安與無奈。（個人觀察）
對方：是喔！
```

## 四、由大到小收斂推力（附完整對話示範）

```
開放問句，運用技巧 → 縮小範圍，確認推力 → 找出推力，重複確認
```
- 開放：「最近工作還好嗎？」「看你最近悶悶不樂，是在工作遇到什麼問題
  嗎？」
- 縮小：「工作上最讓你煩心的事是 A 還是 B 呢？」「你覺得在工作上影響
  你最多的是哪個原因呢？」
- 確認：「你覺得在工作上 OOO 對你來說很重要，對嗎？」「如果 OOO 繼續
  存在，會是你換工作的考量嗎？」

**完整示範對話（接續上段）**：
```
業務：所以你很不能認同你的主管嗎？（跟追）
對方：對啊，他交代事情很不公平，跟他好的人就……，跟他不好的人就做牛
      做馬！
業務：所以你現在跟主管的相處，對你來說是一個很大的困擾嗎？甚至讓你有
      想換工作的念頭嗎？（跟追）
對方：對，我最近真的有在想這件事。
業務：那如果現在有一個好的主管，你剛剛的那些問題就都可以解決了嗎？
      （跟追）
對方：假設你真的換工作了，那要怎麼確定未來一定是個好老闆？（跟追）
業務：那如果又碰到跟現在一樣的情況，是不是就要一直換工作呢？（跟追）
對方：可能吧，看我可以撐多久。
```
**教練診斷邏輯**：像上面這樣一路用跟追把對方帶到「可能吧，看我可以撐
多久」這句話，代表推力已經被確認到位，可以問下一句：「接下來，你會
怎麼繼續下去？」進入下一階段的鋪陳。

## 五、事實、觀點、立場、信仰

- **事實**：有真有假，可驗證。
- **觀點**：每個人都有自己的觀點，無所謂對錯。
- **立場**：不談對錯，只爭輸贏（像辯論賽，一旦認同對方就等於輸了）。
- **信仰**：最難被改變，凌駕在立場之上。

如果增員時總是基於自己的立場或觀點去說服對方，對方不會接受，因為對方
也有對方的立場與觀點。**厲害的人用「為什麼＋觀點」注射別人，愚蠢的人
用「為什麼＋觀點」注射自己**——與其直接反駁，不如先說故事讓對方自己
想一下，再給解決方案。

### 逆火效應與確認偏誤
2006 年密西根大學的實驗顯示：人不喜歡被說服，尤其是那些存在心中根深
蒂固的觀念；當固有概念被新事實證明是錯的時候，人們反而會更堅持原有
的錯誤認知，這在心理學上叫**確認偏誤**，直接反駁只會**逆火**（讓對方
更抗拒）。

## 六、R3 技法庫

### 飛機話術
「如果你現在把你的工作比喻成一架正在飛行的飛機，你覺得這架飛機是：
A. 正在往上飛　B. 在往下飛　C. 平行飛行但是慢慢再降落中？」用這個比喻
問句，判斷準增現在人生起伏的走向，讓他自己說出對現況的感受。

### 1998（或 3396）
引導準增用「中性、客觀的問句」（而不是斷言）一步步計算：
```
收入項（25~55歲工作30年總收入，依假設不同約1998萬或3396萬）
→ 生活費 → 買車 → 養車 → 出國 → 買房 → 養兒 → 退休
→「那我們是不是只剩下 OOO 萬？」
```
每一步都用問句、讓對方自己回答「會不會很困難」「你覺得合理嗎」，而不是
直接告訴他答案——**當你問準增的第一個問題，要讓他心裡點頭「SAY YES」，
他一旦點頭，才有機會一直點下去**。用一張白紙一步步寫給他看（不是準備
好的大本 Show Book，那樣反而會引起防備心）。1998 與 3396 是同一套技法，
只是起薪／加薪幅度假設不同，可依對象情境彈性調整實際數字。

### 人牛馬狗、老虎話術
- **人牛馬狗**：啟發準增思考自己的人生要怎麼過的寓言故事。
- **老虎話術**：一段關於「追求穩定需要付出代價，是否願意接受挑戰」的
  影片。重點是要**陪準增一起看，看完問他「哪一句話或哪一段話最有感覺，
  請他重複講出來，為什麼」**，用他自己的話製造共鳴——只是把連結傳給
  對方看，即使對方很有感覺，但無法再跟他互動、沒有製造共鳴，就沒有
  意義。

## 七、對準增說完暗示性問句後，可能的四種反應

用暗示性問句（如「你有沒有想過，如果都不換工作，一直帶著負面情緒上班
……這真的是你想要過的生活型態嗎？」）之後，準增可能出現：
1. 對保險感興趣（「嗯，那我應該做保險嗎？」）
2. 提出反對問題（「可是公司也有很多人都是這樣子？」）
3. 轉移話題（「這話題太嚴肅了／應該沒這麼嚴重吧」）
4. 直接拒絕（「你要我做保險喔，我不要喔」）

教練要提醒主管：不管出現哪一種反應，都不是壞事，代表推力已經被攪動，
接下來要有耐心繼續經營，而不是急著在這個當下逼對方表態。

## 八、教練回饋輸出格式（建議）

1. **現況釐清**：準增背景、面談聊到的內容、觀察到的推力線索
2. **目標對照**：R3 該做到的三件事（找出推力、確認推力、差異化）
3. **落差診斷**：推力是主觀還是客觀、有沒有誤觸逆火效應、有沒有用故事
   代替直接說服
4. **行動建議**：示範飛機話術、1998 的問句、或人牛馬狗／老虎話術的帶
   入方式
5. **檢核演練**：邀請主管角色扮演練習這場面談
