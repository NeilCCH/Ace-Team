# 成交與轉介 框架卡

## 一、鐵律：先處理痛點，再處理專業

客戶提出的反對問題，第一反應常常是回答「專業問題」（利率、保證、條款）。這是常見盲點——先處理專業會讓客戶覺得你在說服他，而不是理解他。正確順序永遠是：**先回到痛點（同理心＋重新連結那個痛），再處理專業疑慮**。

反對問題三步驟：① 同理心 → ② 先處理痛點（重新扣回 S4 確認過的痛點）→ ③ 再處理專業（理性解釋）。**S6 要扣緊 S4**——處理反對問題時引用的痛點，必須是前面已經確認過的那一個，不是臨場現編。

### 範例（29 歲獨子，痛點：無法照顧愛的人／借人錢的不安）

| 反對問題 | 接法 |
|---|---|
| 「我有點想把錢留著買車耶！」 | 同理（懂你想出遊）→ 先處理痛點（現在花掉，未來父母要用錢時你能無能為力嗎？）→ 再處理專業（用短中長期配置，買車跟孝養都兼顧） |
| 「我手邊存款太低，想留著備用。」 | 同理（是擔心突發支出嗎）→ 先處理痛點（責任只會隨年紀增加，現在不準備未來更難掌握）→ 再處理專業（短中長期配置讓現在未來都有錢用） |
| 「你說的投資型有保證嗎？」 | 先處理痛點（這規劃是保障你對父母的責任跟自己的未來，讓責任跟未來都更確定）→ 再處理專業（誠實說明優缺點，建立理財觀、保險觀） |

## 二、激勵成交：FAB，把利益極大化成一段話

- **特色 Features**：商品有關的資訊或細節
- **好處 Advantage**：商品可以帶給大多數人的好處
- **客戶利益 Benefit**：專屬於這個客戶要的好處

激勵成交 ＝ 彙整一段語言，把商品對這個客戶的利益極大化。手法：把帳戶價值攤開在客戶的人生時間軸上（現在／10年後／20年後／退休時），再對比生活化的等值物（例如「這筆退休金換算成每年出國的次數」），最後回扣到「這些好處，你一個月只繳多少？值不值得？」。

## 三、要求轉介的三個步驟

```
1. 遞送保單後，引導寫反饋卡  →  2. 要求轉介  →  3. 解決顧慮
```

1. **寫反饋卡**：成交後請客戶給具體回饋（對你的建議有沒有幫助？覺得你是什麼樣的業務員？），把回饋寫下來——這是在銷售自己，為轉介鋪路。
2. **要求轉介**：引用客戶剛剛給的正面回饋，直接請他介紹朋友（「可不可以幫我介紹 5 個朋友，我會用對你的方式，談談他的需求」）。
3. **解決顧慮**：主動打消「怕朋友被打擾」的顧慮——不會勉強對方、會回報進度、對他有幫助才談。

**核心觀念**：轉介紹成功與否不取決於話術，取決於你怎麼在客戶面前經營自己、銷售自己。反饋卡只是方法之一，如果業務員有更有效的方法可以用，但沒有具體方法時，從反饋卡開始。

## 四、教練回饋輸出格式（建議）

1. **現況釐清**：摘要這個案子的痛點與 CS123、客戶目前提出的反對問題或成交進度
2. **目標對照**：這階段該做到的三件事——反對問題有沒有先處理痛點、成交話術有沒有把利益極大化、成交後有沒有規劃要轉介
3. **落差診斷**：指出業務員卡在哪一塊——反對問題是不是先講專業沒回痛點？激勵成交是不是只講商品沒有生活化對比？轉介是不是話術到了但沒有先做反饋卡鋪路？
4. **行動建議**：示範反對問題的三步驟接法、一段激勵成交的話術，或轉介三步驟的具體話術
5. **檢核演練**：邀請業務員角色扮演練習反對問題處理或要求轉介，或回述一次「客戶這樣說，我會這樣接」
