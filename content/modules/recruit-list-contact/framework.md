# 增員 R1-R2 框架卡

## 一、R 線全貌

```
R1 取得準增名單 → R2 接觸準增．參加活動 → R3 一次面談．發掘需求（判斷推力）
→ R4 二次面談．說明事業（創造拉力）→ R5 決定聘用．關鍵性面談 → R6 新人報聘
```

**兩種增員路徑，順序不同**：
- **白紙增員**（對方沒有保險業背景）：先做 R3，再做 R4、R5
- **同業增員**（對方本身在保險／金融業）：先做 R4、R5，再做 R3
  （同業已經懂保險，先用專業與制度吸引，最後才深聊個人推力來收斂）

## 二、增員從第一眼就開始了

很多人以為「正式跟對方談工作」才是增員的開始，這個觀念是錯的。準增看到
我們的第一眼，就已經決定他對我們的評價——我們帶給對方的每一個感受，都
是在為後面「對方願意接近我們」埋種子。平時做好信任公式、維持正面形象，
比任何話術都更有力量。

## 三、R1 取得準增名單

### R1 心法：養成增員習慣
LIMRA 數據顯示，準增的來源有 70% 來自於保戶。**重點不在沒有名單，在有
沒有養成「隨時做 25 題」的增員習慣**——無論是做行銷還是保單服務，都要
習慣性地藉機聊聊對方的工作狀況。每一次的面談，其實都是在判斷推力。

### R1 技法
- **白紙增員**：客戶．轉介紹、前同事．客戶轉介紹、外部團體、FB
- **同業增員**：前同事／FB、客戶保單業務轉介、參加外部團體
- **100R 名單**：透過 25 題持續累積 100 個準增名單，每次單位或區部辦
  活動前一週，都把這份名單拿出來看看誰適合這次的活動（例如邀理財有興趣
  的人參加理財講座、邀有家庭孩子的人參加戶外活動、邀注重健康的人參加
  健康講座），藉此增加接觸點，往 R2 推進。

## 四、R2 接觸準增．參加活動

### R2 心法：信任恆等式
```
信任 = 可信度 × 可靠度 × 開誠佈公
        ÷ 自我導向
```
（可信度＝內容上的專業＋承認有不知道的事；可靠度＝說到做到、遵守時間、
交出高品質成果；開誠佈公＝毫無隱瞞、願意分享正式主題以外的話題；自我
導向越低，信任感越高。）

### R2 技法（白紙增員）：工作溫度計 25 題──「增員的保單健診」
- 一份 25 題的問卷，測對方對現在工作的投入度／滿意度。簡單說，**25 題
  就是增員版的保單健診**：不管對方有沒有工作經驗、現在工作好不好都不
  重要，目的只是為了跟對方聊聊他的工作狀況。
- 教練引導語範例：「我想請你用你現在的工作態度／角度填，不要用生活
  態度來填，這樣會更準確。」
- 單數題由左而右 1→2→3→4 分、偶數題由左而右 4→3→2→1 分（反向計分，
  避免作答偏誤），全部加總得出總分。
- **分數區間**（依課程講義明確定義）：
  - 65 分以上：很不滿意現在工作（推力最強，最值得優先推進）
  - 46–64 分：不太滿意或有一點滿意現在工作
  - 45 分以下：很滿意現在工作（推力最弱）
  - 詢問語範例：「你對你現在工作很（不）滿意耶？為什麼？」如果準增回答
    「不是」，也不要反駁他，只是要繼續追問為什麼。
- 就像算命不一定準，但只要真誠關心對方的工作狀況，準增就能敞開心胸，
  拉近跟你的距離——準不準不是重點，聊起來才是重點。

### R2 技法（白紙增員）：社群經營（PO 文分享）
善用 FB 或 IG，每週固定發一篇正面的學習成果（晨會分享、自我學習進修、
紀錄榮耀）。業務員口才好、有說服力只是基本功，重要的是**思維與人不同**
——這種有層次、有深度的內容，要靠不斷練習寫文逐漸培養出來，讓人知道你
不斷在追求進步，你的優秀要讓大家知道。

### R2 技法（白紙增員）：活動邀約
一個持續成長的單位，一定會不斷辦活動增加與準增的接觸點——辦活動是壯大
組織的成功方程式。**邀約活動三個考量點**：有興趣、有需求、同族群。活動
品質與細節會吸引優質準增；請記得，辦烤肉活動時，我們不是真的要去烤肉
的，我們是去增員的——活動細節與整體品質不能鬆懈。

### R2 技法（同業增員）：經營異業結盟
用「雙實支實付」「第三家補強」「躉繳商品」這類專業保單健診話題，跟同業
自然接觸，不用一開口就是增員。

## 五、教練回饋輸出格式（建議）

1. **現況釐清**：準增背景、白紙或同業、目前為止的接觸動作
2. **目標對照**：R1/R2 該做到的事（名單來源健康度、信任恆等式累積）
3. **落差診斷**：卡在哪一步（名單太窄？沒做工作溫度計？信任還不夠？）
4. **行動建議**：下一步具體話術
5. **檢核演練**：邀請主管角色扮演練習接觸對話
