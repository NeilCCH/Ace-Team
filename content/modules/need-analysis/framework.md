# 需求分析 · 找痛點 框架卡

## 一、輸入資料結構（需求確認表，業務員內部也常稱 CN 表）

業務員面談後填寫，教練依此欄位做診斷。

### 背景
- 性別 / 生日（年齡）
- 職業 / 收入
- 關係：緣故 / 轉介 / 陌開 / 其他
- 婚姻 / 子女（人數）
- 行銷級別：S1 取得名單 / S2 約訪取得約會 / S3 初步面談 / S4 發掘需求 /
  S5 說明建議書 / S6 成交

### 現況
- **日常面**：工作 / 家庭 / 生活
- **財務面**：經常帳（收入、支出、結餘）／資本帳（土地、房屋、股票）
  常用探問句：你現在最主要的開銷用在哪裡？／需要拿錢回家嗎？是一定要給的，還是心意呢？／除了生活費、給家裡，還有其他支出嗎？／那這些大概佔你薪水比例有多少？／扣除這些支出，一個月大概會剩下多少？
- **保險面**：現有保障概況
  常用探問句：你有買保單的經驗嗎？／印象最深刻的一張，內容是什麼？／當初是為了什麼（為了誰）而規劃？／內容、額度是自己決定的嗎？（保額、保費）／買多久了？（年期）／跟業務員的關係是？

### 需求訊息
- 「他說」— 3–5 項關鍵句（客戶面談中親口說出的話，逐字或近似記錄）

## 一之一、為什麼要找痛點：黃金圈理論與摩擦力理論

**黃金圈理論（Golden Circle，Simon Sinek）**：所有成功的領導者和品牌，都是由核心理念（Why）開始思考，再向外思考怎麼實現（How），最後才是呈現出的結果（What）。多數業務員卻是反過來——一開口就講商品是什麼（What）、有什麼功能（How），卻沒有先講「為什麼」。核心一句話：**讓客戶購買的，不是你做了什麼，而是你為什麼而做**（People buy why you do it, not what you do）。「找痛點」正是在幫業務員把 Why 講清楚——不是「我要賣你一張保單」，而是「我想解決你剛剛講的那個擔心」。

**摩擦力理論**：想增加射程不能只靠發射力，還要降低阻力；想打動客戶不能只靠商品吸引力，還要降低他心裡的摩擦力。業務員常犯的錯是把全部力氣都花在「增加吸引力」（一直講商品優點），但如果商品優點真的這麼有說服力，應該所有人都會買——沒有，所以**摩擦力沒有被處理掉，比吸引力不夠更常是成交不了的真正原因**。摩擦力常見有四種：慣性、惰性、情感阻力、反彈。「四切三步」找痛點的本質，就是在找出客戶心裡的摩擦力在哪裡、把它降低，而不是一直加碼商品的吸引力。

**教練可以在「目標對照」步驟提醒業務員**：如果一個案子卡住了，先別急著加碼商品賣點，回頭檢查痛點挖得夠不夠深——摩擦力沒降低，吸引力講再多也沒用。

## 二、核心分析方法：找痛點（四個切點）

從客戶「他說」的關鍵句，判斷痛點落在哪個切點：

| 切點 | 說明 | 常見語句線索 |
|---|---|---|
| 愛的人 | 對家人（配偶、子女、父母）的責任與牽掛 | 「小孩」「太太」「家人」「放不下」 |
| 愛自己 | 對自身生活品質、健康、退休的在意 | 「萬一我自己…」「老了以後」 |
| 想做的事 | 未完成的目標、夢想、計畫 | 「想做的事還沒做」「規劃」 |
| 不安全感 | 對風險、意外、財務缺口的擔憂 | 「萬一」「怎麼辦」「貸款」「不夠」 |

一個個案可能同時命中多個切點，教練須明確指出**命中哪些切點**及**判斷依據
（引用客戶原話）**。

## 三、找痛點的提問技巧與例句庫

### 提問三技巧（用在「找出痛點」階段，讓對話不生硬）

| 技巧 | 說明 |
|---|---|
| 跟追 | 順著客戶剛說的話往下問，掌握事實、確認可行性，不要一直開新話題 |
| 第三人 | 用「你同事／你朋友是不是也有一樣的狀況？」把話題連結到第三者，降低戒心 |
| 個人觀察 | 把觀察到的細節說出來（「你以前回訊息很快，最近變慢了」），讓客戶感覺被關注 |

### 示範對話：三技巧合併運用

```
業務：寶寶，最近都好嗎？
對方：還好啊！就是有一點累。
業務：累！是哪方面累啊？（跟追）
對方：就工作啊，主管交辦的事又多又急，讓我有點力不從心。
業務：我可以體會你的難處。（同理心）那你同部門的同事也有一樣的問題嗎？
      一樣一直被交辦事情？（第三人）
對方：都差不多啊，我們主管做事很急，都不給我們喘息空間。
業務：哇！這樣真的很麻煩。（同理心）難怪你回 LINE 的速度及口氣跟平常
      不太一樣。（個人觀察）
對方：喔！怎麼說？
業務：你以前回 LINE 很快，而且口氣很輕鬆，但最近回的速度變慢了，內容
      上也顯得些許的不安與無奈。（個人觀察）
對方：是喔！
業務：那這樣的情況對生活有造成影響嗎？（慢慢切入明確的方向）
```

### 四切點常用探問句（教練給行動建議時可直接引用或改編）

- **愛的人**：你覺得現在對你而言，比較大的責任是什麼？現在的生活中，有沒有誰是你比較放心不下的？你對未來的家庭生活，有沒有希望的樣子？你對將來教育小孩的想法是什麼？你有沒有想過當父母老了，你扮演什麼角色？
- **愛自己**：未來的生活有沒有你希望的樣子？會想怎麼安排？你有沒有想過要對自己好一點？如果讓你安排 20 年的退休生活，你會怎麼安排？眼睛一張開你覺得過什麼樣的生活，是你覺得最開心的日子？
- **想做的事**：目前為止有沒有想完成的事，沒做到會有一點遺憾的？你對未來有沒有階段性的目標，或想完成的事？你有沒有想過五年後的你，想擁有什麼？如果不小心中了 200 萬樂透，你最想完成什麼事？
- **不安全感**：你現在有什麼擔心的事，會影響到你生活的？你曾經有感覺到不安嗎？願意分享嗎？（不安全感沒有辦法有具體問句，是要細心感受的）

教練給「行動建議」時，應優先從這個例句庫挑選、依個案情境改編，而不是憑空造句。

### 傾聽的基本態度

常點頭、給予肯定與讚美、不預設立場、不要只顧自己講——目的是讓客戶放下防備、願意多說。

## 四、痛點深化流程（四步驟，對應教練的診斷階段）

業務訓練部教材把整個找痛點流程統稱為**「4 切 3 步」**：4 個切點（上一節）
配 3 個步驟——找出痛點、確認痛點、擴大痛點。其中「擴大痛點」本身又包含
兩個動作（轉折語、往遠處看）；教練為了逐步診斷方便，把這兩個動作拆成
各自可檢核的步驟，變成下面這四步：

```
1. 揣摩心境    → 業務員是否理解客戶這句話背後的情緒？（對應「找出痛點」）
2. 描述心聲・確認痛點 → 業務員是否用「正面讚美＋把客戶的話重新描述一次」
                 讓客戶自己點頭確認痛點？（對應「確認痛點」）
                 範例句型：「你剛剛說『……』，其實你是一個很＿＿的人耶！」
3. 轉折語      → 業務員是否用「你有沒有發現，有一件事對你的未來很重要，
                 但你現在卻忽略了」之類的句子，帶客戶從現在望向未來？
                 （對應「擴大痛點」的第一個動作）
4. 往遠處看・擴大痛點 → 是否沿人生時間軸（現在 → 中期+6~10年 → 長期+20年）
                 具體描繪缺口若不填補的後果（…怎麼辦？），並回扣到切點？
                 （對應「擴大痛點」的第二個動作）
```

**教練診斷邏輯**：檢查業務員的面談紀錄／對話，走到第幾步就停了，指出
**還沒做的那一步**，並給出下一步的具體話術建議。

### 示範：29 歲獨子（業務訓練部教材原例）

```
他說：姊姊婚後有自己的家庭，以後爸媽應該是我要照顧。

【找出痛點】愛的人、不安全感

【確認痛點】
你剛剛說「以後爸媽應該是你照顧」。其實你是一個很有責任感的人耶！
而且是不是當家人或朋友向你求援時，如果有能力的話，你都會想幫忙啊？

【擴大痛點】
寶寶，你有沒有發現，有一件事對你的未來很重要，但你現在卻忽略了。
你想想看，你接下來有沒有可能邁入人生下個階段？結婚、生子？
未來責任會越小還是越大？如果都不做任何準備，那未來怎麼辦？
```

## 四之一、為什麼「擴大痛點」有效（心理學依據）

康納曼（Daniel Kahneman）與特沃斯基（Amos Tversky）的展望理論（Prospect
Theory）指出：人對「損失」的痛苦感，大約是對等值「獲得」的愉悅感的兩倍
（損失趨避 loss aversion）。這正是「擴大痛點」比「強調利益」更容易打動
客戶的原因——只講保單能帶來什麼好處，客戶感受不到痛；但當痛點被具體
描繪成「不處理會失去什麼」，情緒衝擊才會被放大到足以促成行動。

雷克漢姆（Neil Rackham）的 SPIN 銷售法用兩種問句，補強框架卡「轉折語」與
「往遠處看．擴大痛點」這兩步的提問技巧：

- **植入性問句（Implication Questions）**（對應「往遠處看．擴大痛點」）：
  問「這個問題如果一直沒處理，會怎麼影響到＿＿？」讓客戶自己說出後果有多
  嚴重，比業務員直接說更有說服力。例：「如果貸款還沒還完你就發生萬一，
  孩子的學費誰來出？」
- **解決性問句（Need-payoff Questions）**（對應收斂成 CS123）：問「如果有
  一個方式可以讓你不用擔心這件事，對你來說意味著什麼？」讓客戶自己說出
  解方的價值，而不是業務員替他下結論。

**教練可以在「行動建議」步驟，主動示範一句植入性問句或解決性問句，取代
籠統的「要往遠處看」原則。**

## 五、成交機率自評（痛點深度量尺）

| 級距 | 意義 | 教練判斷準則 |
|---|---|---|
| 30% 痛點淺 | 客戶僅描述現況，未產生情緒共鳴 | 停在「揣摩心境」或更早 |
| 70% 痛點深 | 客戶已確認痛點，情緒有被觸動 | 完成「確認痛點」，但未做「擴大痛點」 |
| 100% 痛死了 | 痛點已擴大到長期後果，客戶主動表態擔憂 | 完成「往遠處看」，時間軸三段都覆蓋 |

**常見盲點（教練要主動提醒）**：業務員在痛點只到 70% 時就急著轉向商品說明，
導致建議書被「我再想想」擋掉。應先做滿「擴大痛點」再收斂。

## 六、建議書結構（收斂輸出，業務訓練部教材稱 CS123）

痛點深化完成後，收斂成三件事：

- **1 個痛點**：找出他在意的事——最核心、客戶自己確認過的那一個（不要多個痛點平均施力）
- **2 個客戶利益**：列出保險對他的價值——商品／方案如何對應解決這個痛點的兩個具體好處
- **3 個反對問題**：提出他可能的反對問題，預判客戶可能提出的三個反對意見，並備妥回應

範例（29 歲獨子）：

| 1 個痛點 | 2 個客戶利益 | 3 個反對問題 |
|---|---|---|
| 無法照顧愛的人 或 借人錢的不安感 | 商品：利變型、投資型；利益：維持孝順的能力 或 用保險抗人性 | ① 我有美元保單了 ② 想把錢留著買車 ③ 存款少想留著備用 |

**過橋到 S5 的收尾句**：「如果有個方式可以解決這些問題，你會不會想聽聽看？」

## 七、售後反饋（閉環）

- **客戶回應**：實際面談後客戶的反應記錄
- **自我反饋**：業務員自己的檢討（哪裡做得好、哪裡卡住）

教練在「檢核演練」步驟，應引導業務員填寫這兩欄，作為下一次個案的養分。

## 八、教練回饋輸出格式（建議）

每次個案分析，教練依通用五步骨架回覆：

1. **現況釐清**：摘要背景、現況、他說的關鍵句，標出命中的切點
2. **目標對照**：說明這階段（S3→S4）應該達成的目標（痛點深化到位）
3. **落差診斷**：指出卡在痛點深化流程的第幾步、成交機率自評落在哪個級距
4. **行動建議**：給下一步具體話術（轉折語／擴大痛點的提問範例）
5. **檢核演練**：邀請業務員回述或角色扮演對練，或提示填寫售後反饋欄
